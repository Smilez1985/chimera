# Messung 2026-11-14 11:15 — Anbieter-Kennung: im Browser durchgespielt

**Anlass:** Nutzerbefund „ich weiß nicht was er in dem Feld Kennung will".
Das Feld ist ein interner Name (`config/anbieter/<id>.json`,
`config/geheim/<id>`), stand aber als Pflichtfeld vor dem Menschen.

**Umgebung:** eigenes Gateway im Sandkasten (`--dienst --socket`, Port
8099, `CHIMERA_CONFIG_DIR`/`CHIMERA_STATE_DIR` auf `/var/tmp`), Passwort
`deepseek`, Anmeldung echt durchgespielt. Commit `62030a5`.

## Was im Browser geprüft wurde

| Prüfung | Ergebnis |
|---|---|
| Feldreihenfolge | **Bezeichnung + Typ** oben, Kennung darunter |
| Kennung folgt der Bezeichnung | „Mein Anbieter (Test)" → `mein-anbieter-test`, „DeepSeek" → `deepseek` |
| Darstellung der Kennung | gedämpft (`class="auto"`, grauer Text/Hintergrund) |
| Anlegen | Anbieter `testanbieter` gespeichert, kein Fehler |
| Schlüsselbereich | `<select>` mit genau den vorhandenen Kennungen, automatisch auf den neuen Anbieter gestellt |
| Schlüssel setzen | „Schlüssel für "testanbieter" abgelegt (wird nie angezeigt).", Feld danach leer, Liste zeigt „hinterlegt" |
| Kennung von Hand groß geschrieben | `auto` fällt weg (der Wert gilt jetzt), Server antwortet: **„Die Kennung "DeepSeek" ist ungueltig: erlaubt sind a-z, 0-9 und "-" (hoechstens 32, kein "-" vorn). Vorschlag: "deepseek""** |

Der letzte Punkt ist der eigentliche Gewinn: Aus „ist ungueltig" ist eine
Meldung geworden, die die Regel und den Ausweg nennt.

## Was dabei aufgefallen ist (für den nächsten Browser-Test)

1. Das Login-Formular hat **drei** Passwortfelder (`e-pw`, `e-pw2` für die
   Ersteinrichtung, `pw` für die Anmeldung). `document.querySelector("input")`
   trifft das versteckte Einrichtungsfeld — der Login scheitert dann mit
   „Passwort falsch", obwohl der Hash stimmt. Richtig ist `#pw`.
2. `pkill -f 'chimera-tor --dienst'` **tötet die eigene Shell**, weil die
   Startzeile im Kommandotext steht. Richtig: `pgrep -x chimera-tor` und
   dessen PID killen.
3. Aufräumen: Testgateway beendet, `/var/tmp/webtest` gelöscht, keine
   Testanbieter im Repo.
